# 駅時刻表と列車の運転日

検索と再生は同じ列車の時刻列を使います。実ダイヤを確認するには、例えば **2026年11月19日** に「京都 → 国際会館」「新神戸 → 三宮」「岡山駅前 → 清輝橋」を検索してください。「京都 → 東山（京都）」では烏丸御池の乗換が入ります。配信元の表を加工して同梱しているため、実ダイヤの利用にも登録やAPIキーは不要です。

京都・神戸のCSVは途中駅の着発を分けて掲載していません。収録された分をその駅の着発両方に使用します。地下鉄各線の2026年12月28日という上限は、未確認の年末年始ダイヤを適用しないためにこの版で定めた収録期限です。公式の次回改正日を表す日付ではありません。祝日・振替休日を内閣府の公表日から判定し、神戸の2025年末年始は市の案内を適用しました。行事時の臨時便や運休情報は追跡していません。[内閣府「国民の祝日」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)・[神戸市交通局 年末年始の運行](https://kotsu.city.kobe.lg.jp/news/information/bus/2025winterholiday/)

## JRのモデル時刻と既存の案内

大阪～京都では新快速・快速・普通ごとに停車駅、走行時間、停車時間、運転間隔を設定しています。新快速は新大阪・高槻に停車します。所要時間の照合には、JR西日本の大阪～京都28分の資料、国土交通省が公表した29分の比較資料、JRの駅時刻表と実際の乗換検索例を使用しました。検索結果にはシミュレーションダイヤと表示します。実際の個々の列車番号、発車分、番線、車両運用を表すものではありません。[JR西日本 Fact Sheets 2025](https://www.westjr.co.jp/company/ir/library/fact/pdf/2025/fact2025.pdf)・[国土交通省 比較資料](https://www.mlit.go.jp/common/001899937.pdf)・[JR大阪駅の駅時刻表](https://timetable.jr-odekake.net/station-timetable/2796011001)・[Yahoo!乗換案内 大阪～京都](https://transit.yahoo.co.jp/search/result?from=%E5%A4%A7%E9%98%AA&to=%E4%BA%AC%E9%83%BD)

JRの長距離経路も、新幹線の乗車駅、敦賀の乗換、瀬戸大橋線の経由地に沿って検索します。日時・曜日・乗換条件ごとの実際の選択肢は、結果にある既存の乗換案内や事業者の駅時刻表で確認できます。

## 再生成する

リポジトリのルートで次を実行します。Python 3.10以降の標準ライブラリを使います。

```powershell
python scripts/prepare-timetables.py --download
```

入力は既定でOSの一時フォルダ内の `railway-source-feeds` に保存されます。元の配信ファイルを別途保存してある場合は、`--inputs` で保存先を指定すると、同じ版のデータをオフラインで再生成できます。

```powershell
python scripts/prepare-timetables.py --inputs C:\railway-source-feeds
```

岡山の固定URLは最新版に更新されるため、取得時期により収録期間と便数が変わります。同梱版のZIPのSHA-256は `e66778c231733fa7725a99f70f39bc096baf1783fe18810014dca8c0f31da4ff` です。路線・乗降制限・停車パターンに予期しない変更があった場合は、変換を停止して箇所を報告します。京都の市ポータルは配布用フォーム、神戸は市カタログが保管するCSVを使用します。新しい改正を入れる際は対象期間、休日や年末年始の例外、列の順序と停車駅の対応も更新します。

出力は `public/data/timetable.json`（出典・カレンダー・便）、`okayama-network.json`（停留場・系統）、`shapes/okaden-*.json`（停留場間の経路）です。保管した原版から変換できること、運転日判定、同名駅を含む接続、時刻の単調増加、午前0時以降の扱いを自動テストで確認できます。
