# はじめての鉄道旅行

初めて開くと、大阪駅の周辺と「大阪 → 京都」の検索結果が表示されます。乗車日は日本の今日、時刻は朝9時です。まず候補を一つ選び、地図の下にある三角形の再生ボタンを押してみましょう。右上の時計が進み、列車が線路に沿って動きます。

## 行きたい駅と日時を決める

1. 左の「出発駅」を押して駅名の一部を入力し、候補から駅を選びます。「到着駅」も同じように選びます。同じ名前が並んだら、下にある都道府県と鉄道会社を見てください。
2. 途中で寄る駅があれば「＋ 経由駅を追加」を押します。たとえば大阪から金沢へ**京都、敦賀の順**で行くなら、経由駅を二つ追加して、上から京都、敦賀を選びます。「↑」でその駅を一つ前へ移し、「×」で外せます。列車がその駅に停車すれば、同じ列車に乗り続けることもできます。
3. 「出発時刻指定」はその時刻以降に出る列車、「到着時刻指定」はその時刻までに着ける列車を探します。「乗車日」と時刻を入力してください。
4. 「経路を検索」を押します。「経路候補」で発着時刻、所要時間、各路線の名前、乗換回数を比べ、乗りたい候補を押します。「停車駅・乗換詳細」を開くと、途中駅の発着や乗換待ちを確認できます。

### 時刻の出どころを見る

「実ダイヤ」の区間には事業者が公開した時刻を使っています。「シミュレーションダイヤ」と表示された区間は、このアプリが作った時刻で走ります。大阪→京都のJR線では、新快速・快速・普通の停車駅と所要時間の違いを反映しています。実際に出かける日は、「同じ条件で乗換案内を確認」から運行予定を調べられます。

駅ひとつの出発時刻をまとめて見たいときは、画面上の「駅時刻表」を開きます。駅と日付を選ぶと、その日の発車便を確認できます。地図に表示される駅を押して「この駅の時刻表」を開く方法もあります。実ダイヤを試すには、たとえば **2026年11月19日 9時** に **新神戸 → 三宮** を検索してください。[実ダイヤの収録期間と出典](TIMETABLE_SOURCES.md)

## 再生とカメラを操作する

| してみたいこと | 操作 |
| --- | --- |
| 発車・一時停止 | 地図下の「再生」を押します。同じ位置の「一時停止」で時計と列車が止まります。もう一度押すと再開します。 |
| 時間を早送り | 「再生速度」で1、2、5、10、30、50、100、200倍を選びます。「表示設定」のスライダーなら1～200倍の間で調整できます。100倍では現実の1秒で車内の時計が1分40秒進みます。 |
| 好きな時刻に移動 | 地図下の横長のタイムラインを動かします。左端は開始、右端は終了です。各駅を見たいときは「前の駅」「次の駅」、終点は「到着まで進む」、やり直すときは「最初に戻る」を押します。 |
| 運転士の視点にする | 「カメラ視点」で「運転席カメラ」を選びます。「追従」は列車の後ろ、「空撮」は上空、「全体俯瞰」は経路全体を映します。「自由」では地図を動かして見たい場所を探せます。 |
| 夜景にする | 「表示設定」を押し、「昼夜モード」で「夜」を選びます。「夕方」「昼」も試せます。「自動」に戻すと、日本の日時と列車の位置に応じて空や照明が変わります。 |
| 地図を広くする | 経路検索パネルを折りたたみます。再び駅を選ぶときは地図上の「経路検索」を押します。対応ブラウザーでは「全画面切替」も使えます。 |

## 二つの列車を同時に走らせる

1. **同じ日の大阪 → 京都** を検索し、候補を一つ選んで「この列車を同時走行に追加」を押します。「追加した列車」に乗車日と発車時刻が表示されます。
2. 別の候補を選ぶか、時刻や駅を変えて再検索します。最後に選んだ候補がメイン列車です。先ほどの列車は追加欄に残ります。両方を同時に見たいときは、二つの旅行の走行時間が重なるように選びます。
3. 「全体俯瞰カメラ」を選び、再生します。追加した列車とメイン列車は、画面右上の**同じ日本標準時の時計**で走ります。タイムラインを動かして、先発列車を後発列車が追いかける様子を確かめてください。
4. 追加した列車が見えないときは、時計の**日付も含めて**発車から到着の間に合わせます。追加列車は発車前と到着後には地図から消えます。メイン列車と同じ便を選択している間は一つだけ表示されます。「追従」はメイン列車を追います。
5. 見終わったら「追加した列車」の右端の「×」で外します。検索条件はしおりボタンで保存したり、リンクボタンで共有したりできます。同時走行の追加一覧はこの画面を開いている間だけ使えます。

## うまく動かないとき

- 駅を選べないときは、駅名の一部だけを入れ、表示された候補を押してください。検索できるのは収録済みの路線・駅です。
- 経路が出ないときは、乗車日、経由順、実ダイヤの収録期間を確認してください。深夜は始発を待つ経路になる場合があります。
- 地図が重いときは「表示設定」で「3D建物」を外せます。外部地図や3D機能が使えない場合は、地図下のメッセージで簡易表示への切替を確認できます。
